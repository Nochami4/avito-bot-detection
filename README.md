# Avito Bot Detection

Решение тестового задания по классификации куки на автоматизированный и человеческий трафик.

Основной файл с решением - `solution.ipynb`.

## Содержимое

- `solution.ipynb` - анализ данных, построение признаков, валидация, сравнение моделей и обучение финальной модели
- `metric.py` - функция расчёта основной метрики
- `submission.csv` - предсказания для `test.csv`
- `requirements.txt` - зависимости проекта

## Запуск

Решение выполнялось на Python 3.14.

Установить зависимости:

```bash
pip install -r requirements.txt
```

Исходные данные необходимо разместить в директории `data/`:

```text
data/
├── train.csv
├── test.csv
└── events.csv.gz

После этого `solution.ipynb` можно выполнить последовательно сверху вниз. В результате будет сформирован файл `submission.csv`.
